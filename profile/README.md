## 🧪 Proyectos y experiencias demostrables | Selected work

### 🏦 Banking Cells Architecture Lab

**[Explorar el laboratorio público](https://banking-cells.consultingriom.com/)**

Laboratorio de arquitectura bancaria basada en células que permite explorar:

- Catálogo y ciclo de vida de células.
- Dominios de negocio y canales.
- Capacidad y enrutamiento de solicitudes.
- Simulación de escenarios sintéticos.
- Analítica operativa y trazabilidad.

**Tecnologías de la edición de laboratorio:** Python · SQLite · HTML · CSS · JavaScript · GitHub Actions.

La demostración utiliza **datos exclusivamente sintéticos**: no se conecta con entidades bancarias ni procesa transacciones financieras reales. Sus conceptos se inspiran en prácticas de diseño por dominios, sin declarar conformidad o certificación oficial con BIAN.

La **Community Edition** se prepara en un repositorio independiente para compartir únicamente código autorizado, sin revelar activos internos de RIOM. Cada repositorio público tendrá sus propias condiciones de licencia.
